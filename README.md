# 🤖 AI Trader - Профессиональная система алгоритмической торговли

**AI Trader** - это продвинутая система алгоритмической торговли для российского рынка, использующая искусственный интеллект для анализа новостей и рыночных данных в реальном времени.

## ✨ Особенности

- 🧠 **Искусственный интеллект** - Нейросетевые модели для анализа новостей и принятия решений
- 📰 **Новостной анализ** - Мониторинг RSS-лент и анализ сентимента в реальном времени
- 📊 **Технический анализ** - Индикаторы, паттерны и рыночная аналитика
- 🛡️ **Risk Management** - Профессиональное управление рисками с лимитами 1-2% на сделку
- 🌐 **Веб-интерфейс** - Современный дашпод с графиками и управлением
- ⚙️ **Гибкая конфигурация** - Все параметры настраиваются через веб-интерфейс
- 📈 **Бумажная торговля** - Режим симуляции для тестирования стратегий

🛡️ Управление рисками

🚨 Устранение неполадок
Распространенные проблемы
"Нет данных с MOEX"

Проверьте подключение к интернету

Убедитесь, что MOEX доступен

Проверьте настройки прокси (если есть)

"Модель не загружается"

Проверьте наличие файлов в models/saved_trader/

Убедитесь, что есть доступ для записи

Проверьте версию PyTorch

"Веб-интерфейс не открывается"

Проверьте, что порт 8050 свободен

Убедитесь, что сервер запущен

Проверьте брандмауэр

"Нет торговых сигналов"

Проверьте настройки RSS источников

Убедитесь, что есть новости

Проверьте порог уверенности модели
